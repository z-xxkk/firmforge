# 设计决定记录

答辩时被问到"为什么这样设计"，答案就在这里。每条决定都写明是谁定的、理由是什么。

状态说明：
- **已定**：项目负责人明确做出的决定；
- **默认**：设计文档采用的方案，负责人还没有明确表态，可以推翻。

Claude Code 实现过程中由负责人新拍板的决定，按同样格式追加在表格末尾。
