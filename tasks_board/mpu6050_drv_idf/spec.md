# MPU6050 驱动（ESP-IDF 新版 I2C 接口）

为接在 I2C 总线上的 MPU6050（三轴加速度 + 三轴陀螺仪）写驱动：初始化、读原始数据、换算成物理量。

## 硬件

- 器件地址 `FF_IMU_ADDR`（0x68，AD0 接低）；I2C 总线由调用方创建好传入，时钟不超过 400 kHz。

## 接口（`include/mpu6050.h`，不能修改）

见头文件。`mpu_init` 设置量程并让器件开始测量；`mpu_read_raw` 读一组原始值；`mpu_read` 读并换算成 g、°/s、°C；`mpu_deinit` 释放（只删自己挂上的设备，不删总线），之后可以再次初始化。

## 要求

1. 初始化先读 WHO_AM_I 确认器件，不对返回 `ESP_ERR_NOT_FOUND`；
2. 器件上电默认处于睡眠模式，必须唤醒；时钟源选 X 轴陀螺的 PLL；
3. 数字低通滤波 DLPF_CFG = 3；
4. 加速度、温度、陀螺数据要一次连续读出（保证是同一时刻的数据）；
5. 换算系数和温度公式按 MPU6050 数据手册；
6. 量程参数超范围返回 `ESP_ERR_INVALID_ARG`；出错返回 `esp_err_t` 错误码。
