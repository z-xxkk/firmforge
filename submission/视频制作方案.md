# 固件工坊演示视频制作方案（草案）

## 一、风格定位：参考了什么，学哪几点

调研的是 2026 年 AI Agent 和开发者工具的演示视频（Anthropic Claude Code、OpenAI Codex、Microsoft Copilot、Cursor、Linear、Stripe 等），以及几篇演示视频的剪辑拆解。只学下面 6 点：

1. **一开场就是产品在干活，不放 logo 片头。** 新一代 Agent 视频先给“一句请求 → Agent 在工作”的画面；带标题卡的从 83% 降到 54%。我们开场 3 秒内就出现输入需求的画面，名字放在第 12 秒左右。
2. **录真实界面，不做假动画。** 大厂的 Agent 演示大多是真实录屏，例如 Anthropic 录的是真实的代码 diff；有拆解指出，动画演示会让人怀疑“软件真的能这样吗”。我们所有界面画面都用真实运行的录屏，动画只用来讲流程和数字。
3. **录屏放在深色渐变底上，配圆角和阴影，镜头跟着重点慢慢推近。** 这是 Screen Studio 那一路的做法，有拆解认为大部分“高级感”来自点击处的平滑推近。我们在关键处推近，例如 449 mV、调度得分、修正时间线。
4. **节奏：先快后稳。** 前 30 秒每个镜头不超过 3 秒；讲核心功能时放慢到 5–7 秒，让人看清。界面好看的 Linear 就用长镜头。等待的部分用 8–16 倍加速，并在画面角上标出“×8”，不剪掉等待，以示真实。
5. **文字少而大。** 关键数字大字居中停留，例如 449 mV → 3005 mV、39% → 67%、0.86 元；每句字幕不超过 12–15 个字；字幕烧进画面，静音也看得懂。
6. **统一的色彩和声音。** 主色用 PPT 的蓝 #0A3AB8，通过用绿、没通过用红；背景音乐用中低速电子乐，讲解时自动压低，切点对齐节拍。

和大厂视频不同的地方：大厂视频一般 45–90 秒，赛题要求 **3–5 分钟**，而且必须展示界面、编排、调度、验证和反馈循环。所以结构是：**30 秒高端开场，加 3 分钟“按章节展开”的真实演示，再加 20 秒数据收尾**。

## 三、需要你录的素材

### A. 一次完整的真实运行（最重要，全程录屏）

- 运行前：板子用 USB 插好，**ADC 那根线先不接**，这样自检会被拦下。
- 软件全屏，系统缩放 100%，深色主题，左边历史列表最好清空。
- 录屏：1920×1080，能选 60 帧就选 60 帧。用 Ubuntu 自带的录屏：按 Print 键，切到“录像”，选全屏。如果有时长限制，再考虑装 OBS（装之前先问你）。
- 从点“新对话”开始，一直录到“完整工程已交付”。中途：
  1. 第一次接线卡片出来时，直接点“已接好，开始自检”，让它测出线没接。
  2. 照清单接好线，再点一次，这次对上。
  3. 全部跑完后，点工程图上的一个模块，依次点“过程”“调度”“上板”标签，每个停 3 秒。
  4. 点“导出代码”，文件夹窗口停 2 秒。
- 鼠标动作慢一点，不用的时候不要晃。等待时不用操作，我会加速处理。
- 预计 20–25 分钟，花费约 0.9 元（快档）。

### B. 几段短录屏（每段 10–20 秒）

1. 知识库：搜索框输入 WHO_AM_I，点“手册和实测对不上”那一条。
2. 团队：点 coder-fast，停 3 秒。
3. 工作流：选 firmware_review → 点“适应画布” → 点“开始检查” → 点开一种预演情况，看步骤依次亮起。

### C. 手机实拍（横拍，光线好，手机放稳或靠着东西）

1. 开发板放在桌上的特写，5 秒，镜头慢慢推近。
2. 手把杜邦线插到 3V3 的特写，5 秒。
3. 插 USB 线的特写，3 秒。
4. 可选：录电脑屏幕的全景，带一点桌面环境，5 秒。

## 四、需要你决定的事

1. **制作工具**：本机没有 ffmpeg，也没有剪辑软件。推荐用 Remotion：用代码做视频，动效、字幕、推近都能精确控制，个人和学生免费，自带 ffmpeg。需要在 `submission/video/` 下用 npm 安装，约几百 MB，还会下载一个无界面的 Chrome。装之前要你同意。
2. **旁白**：
   - 你自己配音：最真实，评委听得清思路。我给逐句稿，你用手机在安静的房间分段录。
   - AI 配音：要装一个工具，用的是联网服务，声音有点“播音腔”。
   - 只放音乐和字幕：Anthropic、OpenAI 的演示就是这样，但 3 分多钟全靠字幕，评委可能看得累。
3. **背景音乐**：请你选一首免版权的曲子，例如 YouTube 音频库或 Pixabay 的中低速电子乐，下载后放进 `submission/video/素材/`。我不自己下载。
