# 1-Wire 温度传感器 DS18B20 驱动 onewire_ds18b20

实现 `include/onewire_ds18b20.h` 中声明的全部函数：在 1-Wire 总线上找出所有设备（ROM 搜索），让所有 DS18B20 同时测温，再逐个读出温度。

## 约束

- 不能使用动态内存、标准输入输出函数和浮点运算，不能用递归。
- 只能通过 `include/hal_onewire.h` 里的三个函数访问总线，不能自己实现它们（由使用方提供；写单元测试时请在 `tests/` 里自己写一个模拟实现，能挂多个假设备、按"线与"返回读到的位）。
- 两个头文件都由任务锁定，不能修改。

## 总线接口

| 函数 | 说明 |
|---|---|
| `hal_ow_reset()` | 复位脉冲；有设备应答返回 true |
| `hal_ow_write_bit(bit)` | 写一个位（0 或 1） |
| `hal_ow_read_bit()` | 读一个位；总线是"线与"：任何一个参与的设备发 0，读到的就是 0 |

**所有命令和数据都是低位先发、低位先收**（一个字节按 bit0、bit1……bit7 的顺序）。

## 资料（摘自 Maxim 应用笔记 AN187 与 DS18B20 数据手册）

**ROM 号**：64 位。`rom[0]` 是家族码（DS18B20 为 28h），`rom[1..6]` 是 48 位序列号，`rom[7]` 是前 7 字节的 CRC。

**CRC-8**：多项式 X^8 + X^5 + X^4 + 1，初值 0，每个字节低位先算（反射写法的多项式为 8Ch）。对数据连同它末尾的 CRC 字节一起算，结果为 0 表示正确。核对用："123456789" 的 CRC 是 A1h。

**ROM 搜索（AN187）**：一轮搜索 = 复位 → 写 F0h → 对第 1 到第 64 位（bit 1 是 rom[0] 的最低位）依次：读一位（所有参与设备该位的"线与"）、再读一位（该位取反后的"线与"）、写一位"方向"。只有这一位等于方向的设备继续参与，其余设备退出，直到下次复位。

| 读到的两位 | 含义 | 方向 |
|---|---|---|
| 0、1 | 参与的设备这一位都是 0 | 0 |
| 1、0 | 参与的设备这一位都是 1 | 1 |
| 0、0 | 有 0 也有 1（分歧） | 见下表 |
| 1、1 | 没有设备参与 | 终止本轮，返回 `OW_ERR_BUS` |

分歧时，与"上一轮记下的分歧点"比较当前位置：

| 当前位置与上次分歧点相比 | 方向 |
|---|---|
| 小于 | 与上一轮找到的 ROM 号这一位相同 |
| 等于 | 1 |
| 大于 | 0 |

本轮中最后一个"分歧且方向为 0"的位置，成为下一轮的分歧点（第一轮的分歧点为 0）。64 位走完就得到一个 ROM 号；若下一轮的分歧点为 0，说明这是最后一个设备。

**DS18B20 命令**：匹配 ROM 55h（后跟 8 字节 ROM 号）、跳过 ROM CCh（同时寻址所有设备）、开始转换 44h、读暂存器 BEh。

**转换**：44h 之后，读时隙在转换进行中读到 0，完成后读到 1。

**暂存器**：9 字节。第 0、1 字节是温度（低字节在前），第 4 字节是配置寄存器，第 8 字节是前 8 字节的 CRC。

**温度格式**：16 位有符号数（二进制补码），单位 1/16 °C。例：07D0h = +125 °C，0191h = +25.0625 °C，FF5Eh = −10.125 °C，FC90h = −55 °C。上电时温度寄存器为 0550h（+85 °C）。

**分辨率**：配置寄存器的 bit6、bit5（R1、R0）：00 = 9 位、01 = 10 位、10 = 11 位、11 = 12 位。11 位时温度最低 1 位无意义，10 位时最低 2 位无意义，9 位时最低 3 位无意义。

## 函数行为

**`ow_crc8(data, len)`**：按上面的 CRC-8 计算；data 为 NULL 返回 0。

**`ow_search_all(roms, max, found)`**

- 按 AN187 反复搜索，直到最后一个设备，把 ROM 号按找到的顺序写进 `roms[0]`、`roms[1]`……，`*found` 为找到的个数，返回 `OW_OK`。
- 第一次复位没有设备应答：返回 `OW_ERR_NO_DEVICE`，`*found` 为 0。之后某一轮复位没有应答：返回 `OW_ERR_BUS`。
- 某一轮读到 1、1：返回 `OW_ERR_BUS`。
- 某一轮得到的 ROM 号 CRC 不对：返回 `OW_ERR_CRC`。
- 出错时 `*found` 为出错之前已经找到的个数。
- 已经找到 max 个，总线上还有设备（又搜到一个有效的 ROM 号）：返回 `OW_MORE`，`*found` 为 max，不写 `roms[max]` 及以后。正好 max 个设备时返回 `OW_OK`。
- roms 或 found 为 NULL、max 为 0：返回 `OW_ERR_PARAM`，不碰总线。

**`ds18b20_convert_all()`**

- 复位（没有应答返回 `OW_ERR_NO_DEVICE`）→ 写 CCh → 写 44h → 反复读一位，读到 1 返回 `OW_OK`。
- 最多读 `DS18B20_MAX_CONVERT_POLLS` 次仍是 0：返回 `OW_ERR_TIMEOUT`。

**`ds18b20_read_temp(rom, centi_celsius)`**

- rom 或 centi_celsius 为 NULL：返回 `OW_ERR_PARAM`，不碰总线。
- `rom->rom[0]` 不是 28h：返回 `OW_ERR_NOT_DS18B20`，不碰总线。
- 复位（没有应答返回 `OW_ERR_NO_DEVICE`）→ 写 55h → 写 8 字节 ROM 号（rom[0] 先写）→ 写 BEh → 读 9 字节暂存器。
- 暂存器 CRC 不对：返回 `OW_ERR_CRC`，不修改 `*centi_celsius`。
- 按配置寄存器的分辨率把无意义的低位清 0，再换算：温度 = 原始值 × 100 ÷ 16，用 32 位整数、C 语言整数除法（向零取整），单位 0.01 °C。例：0191h → 2506，FF5Eh → −1012，FFF8h → −50。
- 读到 +85 °C（上电值）照常返回，不当作错误。
- 任何错误都不修改 `*centi_celsius`。
