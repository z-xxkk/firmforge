# MPU6050 姿态传感器驱动 mpu6050_drv

实现 `include/mpu6050.h` 中声明的全部函数：通过 I2C 初始化 MPU6050，并读取加速度、温度、角速度。

## 约束

- 不能使用动态内存、标准输入输出函数和浮点运算，不能用递归。
- 只能通过 `include/hal_i2c.h` 里的两个函数访问芯片，不能自己实现它们（由使用方提供；写单元测试时请在 `tests/` 里自己写一个模拟实现）。
- 两个头文件都由任务锁定，不能修改。

## 芯片资料（摘自 InvenSense《MPU-6000/MPU-6050 Register Map and Descriptions》Rev 4.0）

| 内容 | 说明 |
|---|---|
| I2C 地址（7 位） | AD0 引脚接低：0x68；接高：0x69 |
| WHO_AM_I（0x75） | 只读，值为 0x68 |
| PWR_MGMT_1（0x6B） | 上电默认 0x40（睡眠）。bit6 = SLEEP；bit2:0 = CLKSEL，1 表示以 X 轴陀螺仪为参考的 PLL（手册建议使用陀螺仪时钟） |
| GYRO_CONFIG（0x1B） | bit4:3 = FS_SEL：0 → ±250 °/s（131 LSB/(°/s)），1 → ±500（65.5），2 → ±1000（32.8），3 → ±2000（16.4） |
| ACCEL_CONFIG（0x1C） | bit4:3 = AFS_SEL：0 → ±2 g（16384 LSB/g），1 → ±4 g（8192），2 → ±8 g（4096），3 → ±16 g（2048） |
| 数据寄存器 0x3B–0x48 | 共 14 字节，依次为 ACCEL_X、ACCEL_Y、ACCEL_Z、TEMP、GYRO_X、GYRO_Y、GYRO_Z，每个 2 字节、**高字节在前**、16 位有符号数 |
| 连续读 | 一次连续读出这 14 字节，才能保证它们来自同一个采样时刻 |
| 温度 | 温度(°C) = 原始值 / 340 + 36.53 |

## 初始化 `mpu6050_init(dev, ad0_high, accel_range, gyro_range)`

1. 检查参数：dev 为 NULL、量程不在 0–3 内，返回 `MPU6050_ERR_PARAM`，不访问总线。
2. 读 WHO_AM_I：必须是 0x68，否则返回 `MPU6050_ERR_ID`，之后**不做任何写操作**。
3. 向 PWR_MGMT_1 写 0x01（退出睡眠，时钟选 X 轴陀螺仪 PLL）。
4. 向 GYRO_CONFIG 写 `gyro_range << 3`，向 ACCEL_CONFIG 写 `accel_range << 3`（其余位为 0，不开自检）。
5. 全部成功返回 `MPU6050_OK`，之后才可以读数据。

任何一次 I2C 操作失败，立即返回 `MPU6050_ERR_BUS`，不再进行后续步骤。初始化没有成功（任何错误）时，驱动处于"未就绪"状态。

## 读数据 `mpu6050_read(dev, out)`

- dev 或 out 为 NULL，或者驱动未就绪：返回 `MPU6050_ERR_PARAM`，不访问总线。
- 从 0x3B 开始**一次**连续读 14 字节；I2C 失败返回 `MPU6050_ERR_BUS`，**不修改** `*out`。
- 成功时填写原始值和换算值，返回 `MPU6050_OK`。

换算一律用 32 位整数，C 语言整数除法（向零取整）：

| 字段 | 单位 | 公式 |
|---|---|---|
| `accel_mg[i]` | mg（千分之一 g） | 原始值 × 1000 ÷ 加速度灵敏度（16384 / 8192 / 4096 / 2048） |
| `gyro_cdps[i]` | 0.01 °/s | 原始值 × 1000 ÷ (陀螺仪灵敏度 × 10)，即除以 1310 / 655 / 328 / 164 |
| `temp_cdeg` | 0.01 °C | 原始值 × 100 ÷ 340 + 3653 |

例：±2 g 量程下 ACCEL_X 原始值 16384 → 1000 mg；±250 °/s 量程下 GYRO_X 原始值 131 → 100（即 1.00 °/s）；温度原始值 0 → 3653（36.53 °C）。
