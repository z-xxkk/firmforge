# 窗口 5 的中值滤波 median_filter

实现 `include/median_filter.h` 中声明的全部函数。用途：传感器偶尔读出离谱的值（毛刺），中值滤波取最近 5 个读数的中位数，把毛刺挤掉。

## 约束

- 不能使用动态内存和标准输入输出函数，不能用递归。
- 状态结构体由调用方提供；`median_filter_t` 的字段由头文件给出，实现只能使用这些字段，头文件不能修改。
- 读数是 `int16_t`，范围 -32768 到 32767，任何情况下都不能溢出。

## 中位数的定义

把窗口里的读数从小到大排好：
- 个数为奇数：取正中间那个；
- 个数为偶数：取中间两个的平均，**整数除法向零取整**（即 C 语言 `/` 的结果，例如 -3 和 0 的平均是 -1，3 和 4 的平均是 3）。计算时要用足够宽的整数类型，避免两数相加溢出。

## 函数行为

| 函数 | 正常行为 | 异常 / 边界 |
|---|---|---|
| `median_filter_init(f)` | 清空，读数个数为 0 | f 为 NULL：什么都不做 |
| `median_filter_push(f, sample, out)` | 把 sample 加入窗口；窗口已有 5 个时先丢掉**最早**的一个；然后把当前窗口的中位数写到 `*out`，返回 true | f 或 out 为 NULL：返回 false，**窗口不变** |
| `median_filter_get(f, out)` | 把当前窗口的中位数写到 `*out`，返回 true；窗口内容不变 | f 或 out 为 NULL，或者还没有任何读数：返回 false，不修改 `*out` |
| `median_filter_count(f)` | 窗口里当前的读数个数（0–5） | f 为 NULL：返回 0 |
| `median_filter_reset(f)` | 清空，之前的读数全部作废 | f 为 NULL：什么都不做 |

不足 5 个读数时，用已有的读数按上面的定义算中位数。

## 例子

| 依次推入 | 每次返回 |
|---|---|
| 10 | 10 |
| 20 | 15（10 和 20 的平均） |
| 1000 | 20 |
| 30 | 25（20 和 30 的平均） |
| 40 | 30 |
| 50 | 40（窗口变成 20, 1000, 30, 40, 50） |
