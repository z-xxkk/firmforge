## 二、按分值排的优先级（初赛 100 分）

1. **文档质量 25 分**：方案书 ≥ 5000 字（8 部分）、PPT 10–15 页、3–5 分钟视频。完全没开始。
2. **可靠性与可复现性 25 分**：要先用真实模型跑完整评测，材料里每个数字都要有出处；Windows 实测、一键复现说明。
3. **AI 使用充分性 25 分**：功能已有；方案书里要写清每个环节 LLM、RAG、MCP 的作用、贡献和局限，以及 Prompt 是怎么设计的。
4. **功能完整性 25 分**：基本齐全。

## 三、可以补的功能（需要负责人决定做不做）

- **A. 收敛曲线**：评测里加"第 1、2、…、n 轮累计通过率"，full 与 b2、消融配置画在一张图上。只改统计，不改 Agent 看到的内容，不影响评测数据。约半天。
- **B. 提示词自适应**：一批运行结束后，让一个 Agent 读失败记录，提出对某个 Agent 提示词的修改，保存为新版本（不自动启用，人确认后启用），再用评测比较新旧版本。会改变 Agent 行为，要在全量评测之前做完，否则数据要重跑。约 1–2 天。
- **C. 调研 LobeHub**：查一手资料，在方案书"同类对比"一节写清我们借鉴了什么、哪里不同。不改代码。
