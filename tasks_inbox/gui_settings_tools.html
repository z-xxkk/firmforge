把 FirmForge 当工具给别人用（MCP 服务端）

在 Claude Code、Cursor 等支持 MCP 的工具里加上下面这段，它们就能调用 FirmForge 的判定器检查 C 代码。

{
  "mcpServers": {
    "firmforge": { "command": "firmforge", "args": ["mcp"] }
  }
}
