## 一、视觉风格

### 方向

**安静的浅色工作台**：浅灰底上放几块白色圆角面板，面板之间留 8 像素的缝，这道缝就是拖动调整大小的地方。没有阴影、没有渐变、没有装饰图案，信息靠字重、留白和少量颜色区分。唯一的强调色是一种沉稳的松石绿，只用在"通过、已接通、你的消息、当前选中"这几处。

### 配色

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 雾灰（底色） | #F3F4F6 | 窗口底、面板之间的缝、次要块的底 |
| 纸白（面板） | #FFFFFF | 所有面板 |
| 墨色 | #1C2026 | 正文、主按钮（黑底白字） |
| 次要文字 | #6E7580 / #9AA0A8 | 说明、标签、未开始的内容 |
| 细线 | #E4E6EA | 表格分隔、输入框边框 |
| 松石绿（唯一强调色） | #2F6F68，浅底 #E6F0EE | 通过的检查条、已接通的依赖线、你的消息气泡、开关 |
| 状态色 | 琥珀 #C98A2B 进行中、砖红 #C8483D 失败、绿 #3E8E63 通过 | 状态小圆点、进行中模块的柔光框 |

状态色都调得比第 3 版柔和（降低饱和度），避免刺眼。

### 圆角（按层级区分，不是一刀切）

| 元素 | 圆角 |
|---|---|
| 面板 | 16 像素 |
| 模块节点、输入区、代码块 | 12–14 像素 |
| 按钮、输入框 | 10 像素 |
| 标签、选择小块、发送按钮 | 完全圆（胶囊形 / 圆形） |
| 检查进度小条 | 3 像素（两头圆） |

### 线条

- 模块图和流程图的连线全部改成**平滑曲线**（贝塞尔曲线），不再是直角折线。
- 已接通的依赖用松石绿实线，还没接通的用浅灰点线。
- 图标用圆头、圆角的细线条（线宽 1.6）。

### 字体

界面文字用系统中文黑体（Windows 微软雅黑、Linux 思源黑体）；模块名、Agent 名、文件名、代码用 JetBrains Mono。字号只用 4 级：20（页面标题）、15（区块标题）、13（正文）、11–12（说明）。

## 二、窗口大小都能调

| 规则 | 说明 |
|---|---|
| 相邻面板之间都有分隔条 | 用 Qt 的 `QSplitter`：鼠标移到缝上变成双向箭头，拖动改宽或改高；缝中间的灰色小短条提示"这里能拖" |
| 每个面板有最小尺寸 | 拖到最小就停，不会被挤没；会话列表、步骤箱等侧栏可以拖到底**折叠**，再拖出来恢复 |
| 双击分隔条 | 恢复默认比例 |
| 记住你的布局 | 每个页面的面板尺寸关闭软件时保存（`QSettings`），下次打开还原 |
| 设计器的面板还能挪位置 | 步骤箱、步骤树、属性、代码四块用 Qt 的停靠窗口（`QDockWidget`），和 Qt Designer 一样可以拖到别的边、叠成标签页或拉出来变成浮动小窗 |
| 窗口整体 | 最小 1200 × 760；缩小时右侧详情区先变窄，再自动收起会话列表 |

- 左边会话列表（点历史会话可回放）；中间对话；右上模块图（可切成流程图）；右下详情。
- 每个 Agent 一个圆形头像（首字母，按角色用不同的浅色底）；你的消息用浅绿气泡。
- 检查结果是一行 5 段小圆条；工具调用是一行浅灰圆角条，点开看完整参数和返回。
- 输入框是一个圆角大框，下沿放"模型、思考、配置"三个胶囊选择和圆形发送按钮；支持 `@` 引用和斜杠命令（`/model`、`/think`、`/task`、`/workflow`）。
- 模块图：每个模块一个白色圆角卡片，右上状态圆点，下沿 5 段检查进度条；进行中的模块外面一圈琥珀色柔光；连线是平滑曲线。

## 四、工作流设计器（[gui_designer.png](gui_designer.png)）

和 Qt Designer 的对应关系不变：左"步骤箱"、中"画布"、右上"步骤树"、右下"属性"、下方"`workflows/*.toml` 实时代码 + 检查结果"。改动只在样式：
- 画布底色是很淡的点阵，不再是原理图网格；
- 步骤是白色圆角块，"等人确认"用胶囊形虚线框，新加的步骤用浅绿底标出；
- 连线是曲线；子流程是一块半透明的大圆角区域；
- 版本信息是左下角一张小卡片（不再是原理图标题栏）。

设计器的功能（拖拽、子流程、属性、保存前检查、图和代码同一份、版本、让 AI 改、试运行）同第 3 版。

## 五、设置（[gui_settings.png](gui_settings.png)、[gui_settings_tools.png](gui_settings_tools.png)）

分类不变：通用、模型、工具与 MCP、记忆与知识库、人工与权限、预算、高级。右上角"打开 firmforge.toml"。工具与 MCP 页按 [tools_mcp_framework.md](tools_mcp_framework.md) 第 2 版更新：按**工具集**列出内置工具；外部 MCP 服务显示协议版本、状态、工具名、"调用前问我"和启用开关。

## 六、统一的"任务单"格式

同第 3 版：发给任何 Agent 的用户消息都按"意图 / 当前位置 / 引用 / 约束 / 附件"5 节组织；画布上的步骤以它的 TOML 代码出现在"引用"里，和贴一个 `.c` 文件一样。对话里每条 Agent 消息都能点开"发给 AI 的内容"。

## 七、对照 skill 的自查

| skill 点名的模板化样式 | 这一版 |
|---|---|
| 奶油底 + 赤陶色强调 | 没有：底色是冷灰，强调色是松石绿 |
| 近黑底 + 一个亮色 | 没有：整体浅色 |
| 报纸式细线密排 | 没有：留白充足 |
| **千篇一律的圆角卡片 + 同样的灰阴影 + 渐变** | **这一版风险最大**（你要求圆角）。处理：面板不加阴影，只靠底色差区分；圆角按层级分 5 档，不是一种圆角用到底；不用渐变；对话消息不做成卡片；整页只有输入框一处带极淡阴影（表示它浮在上面、可以输入） |
| 中间点拼信息、全大写小标签 | 没有（截图自评时发现 3 处中间点，已改成逗号） |

截图自评后改掉的问题：
- 模块卡片和诊断消息里残留的"·"中间点，已改成逗号；
- 外部 MCP 服务的开关是关的，状态栏却写着"已连接"，前后矛盾，已改成"未启用"。
